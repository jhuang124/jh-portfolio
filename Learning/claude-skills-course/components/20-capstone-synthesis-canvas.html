Component 20

Capstone Synthesis Canvas

Build your own concept map. Click a source concept, then click a target to draw a connection. Label each connection with how the two ideas relate. This is your personal understanding artifact.

Usage

const anchors = [
  { id: 'description', label: 'Description = Routing Label', x: 150, y: 120 },
  // ...more anchors
];

html\`<\${SynthesisCanvas} anchors=\${anchors} />\`
