Sequence Diagram Stepper

Walk through the skill injection pattern message by message. Step forward and backward to see how Claude routes queries through the skill system.

Usage

const participants = [
  { id: 'user', label: 'User', color: '#67e8f9' },
  // ...
];

const messages = [
  { from: 'user', to: 'engine', label: 'Query', payload: '...', description: '...' },
  // ...
];

html`<${SequenceDiagramStepper} participants=${participants} messages=${messages} />`
