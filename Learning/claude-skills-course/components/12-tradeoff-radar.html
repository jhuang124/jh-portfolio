Component 12

Tradeoff Radar Overlay

Compare skill architecture patterns across five dimensions. Toggle patterns on and off to see how their shapes overlap and diverge. Hover any axis for an explanation.

Usage

const axes = [
  { key: 'simplicity', label: 'Simplicity', tip: '...' },
  // ...
];

const options = [
  { id: 'mono', label: 'Monoskill', color: '#fbbf24', values: { simplicity: 0.9, ... } },
  // ...
];

html`<${TradeoffRadar} axes=${axes} options=${options} />`
