Component 09

Code Surgery Canvas

Find the bug, click the broken line, type your fix. Wrong line gives a hint. Right line, wrong fix shows what's actually needed. Work through all 3 cases.

Usage

const cases = [
  {
    title: "Case title",
    description: "What's wrong here?",
    lines: [
      { text: "code line 1", editable: false },
      { text: "buggy line", editable: true, fix: "correct version", hint: "Look at..." },
      // ...
    ]
  }
];

html\`<\${CodeSurgeryCanvas} cases=\${cases} />\`
