Component 15

Causal Chain Builder

Trace the consequences of a vague skill description. At each step, choose what happens next. Watch the chain of failure grow -- and discover where branching paths diverge.

Usage

const chainData = {
  root: { text: 'Starting event', reason: null },
  steps: [
    {
      id: 's1',
      options: [
        { id: 'a', text: 'Effect A', reason: 'because...', correct: true, next: 's2' },
        { id: 'b', text: 'Effect B', reason: 'because...', correct: false },
      ]
    },
    // ...
  ]
};

html`<${CausalChainBuilder} data=${chainData} />`
