Component 08

Drag-to-Canvas Composer

Click blocks from the palette, then click a canvas slot to place them. Build a skill directory structure by snapping blocks into the right positions.

Usage

const composerData = {
  blocks: [
    { id: "file1", label: "file.md", category: "file", icon: "doc" },
    // ...
  ],
  slots: [
    { id: "slot1", label: "Root config", accepts: ["file1","file2"], group: "structure" },
    // ...
  ],
  connections: [
    { from: "slot1", to: "slot2" }
  ]
};

html\`<\${DragToCanvasComposer} data=\${composerData} />\`
