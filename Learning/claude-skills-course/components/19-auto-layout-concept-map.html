Component 19

Auto-Layout Concept Map

A dependency graph of the 14 core Claude Skills concepts. Click any node to highlight its prerequisites (upstream) and dependents (downstream). Color-coded by category.

Usage

const nodes = [
  { id: 'what-skills-are', label: 'What Skills Are', category: 'foundation',
    description: '...', x: 80, y: 200 },
  // ...more nodes
];
const edges = [
  { from: 'what-skills-are', to: 'two-part-file' },
  // ...more edges
];

html\`<\${ConceptMap} nodes=\${nodes} edges=\${edges} categories=\${categories} />\`
