Component 14

Live Code Sandbox

Write a SKILL.md description field. Watch the live preview show which queries would trigger your skill, track your character budget, and see which quality criteria you've met.

Usage

const checks = [
  { id: 'verb', label: 'Has action verb?', test: (code) => /^(Use|Run|Create|Generate|Review|Deploy|Analyze)/i.test(code.trim()) },
  // ...
];

const testQueries = [
  { query: 'Sample query', keywords: ['keyword1', 'keyword2'] },
  // ...
];

html`<${LiveCodeSandbox} checks=${checks} testQueries=${testQueries} maxChars=${250} placeholder="..." />`
