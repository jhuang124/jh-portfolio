Component 17

Abstraction Ladder

Navigate between concrete examples, general principles, and meta-frameworks. Click any level to expand it. Switch between ladders to see how different specifics map to the same structural patterns.

Usage

const ladders = [
  {
    id: 'a', title: 'Description Design',
    levels: [
      { level: 'concrete', label: 'Example', content: '...', detail: '...' },
      { level: 'principle', label: 'Principle', content: '...', detail: '...' },
      { level: 'meta', label: 'Meta-Framework', content: '...', detail: '...' },
    ]
  },
  // ...more ladders
];

html\`<\${AbstractionLadder} ladders=\${ladders} />\`
