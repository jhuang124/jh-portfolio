Component 06

Morphing Side-by-Side Compare

Drag the slider to morph between a weak and strong version. Annotations appear at key thresholds showing exactly what changed and why.

Usage

const compareData = {
  title: "Before vs After",
  lines: [
    {
      bad: "Vague text here",
      good: "Specific, actionable text here",
      annotation: "Why this change matters",
      threshold: 0.3  // when annotation appears (0-1)
    },
    // ...more lines
  ]
};

html\`<\${MorphingSideBySide} data=\${compareData} />\`
