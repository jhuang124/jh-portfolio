Component 07

State Machine Navigator

Navigate a skill lifecycle by clicking transitions. The current state pulses. Invalid paths are dimmed. Your history trail builds as you explore.

Usage

const machine = {
  states: {
    idle: { label: "Idle", x: 100, y: 200, description: "..." },
    // ...
  },
  transitions: [
    { from: "idle", to: "active", label: "start", description: "..." },
    // ...
  ],
  initial: "idle"
};

html\`<\${StateMachineNavigator} machine=\${machine} />\`
