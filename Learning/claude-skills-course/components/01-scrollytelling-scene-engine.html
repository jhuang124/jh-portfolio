Component 01

Scrollytelling Scene Engine

Sticky visual stage + scrolling text panels. The visual transforms in response to scroll position. The learner reads at their own pace while the diagram evolves to match the narrative.

Usage

// Define your scene steps — each step has a narrative card
// and a render function that returns the visual for that step.

const steps = [
  {
    label: "Step label",
    title: "Card Title",
    body: "Explanatory text for this step.",
    render: (active) => html\`<\${YourVisualComponent} active=\${active} />\`
  },
  // ... more steps
];

html\`<\${ScrollytellingScene} steps=\${steps} />\`
