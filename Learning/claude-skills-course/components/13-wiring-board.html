Component 13

Wiring Board

Connect user queries to the skill that would fire. Click a query on the left, then click the matching skill on the right. Wrong connections flash red. Complete all five to activate the system.

Usage

const pairs = [
  { left: { id: 'q1', label: 'Query text' }, right: { id: 's1', label: 'Skill name' } },
  // ...
];

html`<${WiringBoard} pairs=${pairs} />`
