Component 10

Exploded Layer View

Click to explode the stack and reveal internal structure. Click a layer to isolate it. Connection lines show how layers communicate. Click the background to reassemble.

Usage

const layers = [
  {
    id: "layer1",
    label: "Top Layer",
    subtitle: "Always loaded",
    color: "#a78bfa",
    contents: [
      { label: "field-name", description: "What this contains" }
    ]
  },
  // ...more layers
];
const connections = [
  { from: "layer1", to: "layer2", label: "triggers" }
];

html\`<\${ExplodedLayerView} layers=\${layers} connections=\${connections} />\`
