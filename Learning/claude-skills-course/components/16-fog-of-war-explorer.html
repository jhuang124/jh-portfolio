Component 16

Fog-of-War Explorer

Click the foggy regions to reveal the Claude Skills ecosystem. Each reveal exposes connections to previously discovered nodes. Explore at your own pace until the full map emerges.

Usage

const regions = [
  { id: 'skill-md', label: 'SKILL.md', x: 400, y: 200,
    description: 'The main skill file.' },
  // ...more regions
];
const connections = [
  { from: 'skill-md', to: 'frontmatter', label: 'contains' },
  // ...more connections
];

html\`<\${FogOfWarExplorer} regions=\${regions} connections=\${connections} />\`
